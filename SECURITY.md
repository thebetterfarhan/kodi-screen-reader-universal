# Security policy

Supported security fixes are made against the latest release.

Do not attach unsanitized Kodi logs to a public issue. Logs can contain Windows usernames, filesystem paths, media titles, add-on names, and network addresses. Use GitHub's private security-advisory reporting for vulnerabilities. Ordinary bugs and compatibility reports can use public issues after private data is removed.

The Windows installer is currently unsigned. Verify downloads using the published SHA-256 checksums and download only from this repository's Releases page.
