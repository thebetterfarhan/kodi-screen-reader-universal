# Kodi Screen Reader 2.1.1

This patch release adds dedicated compatibility for Kodi's default Estuary skin while retaining the universal Tolk and responsive-navigation work from version 2.1.0.

## Highlights

- Announces Estuary Home sections and widget areas.
- Prefers the focused Estuary container, preventing stale titles from another widget.
- Adds stable widget focus identity and utility-button roles.
- Ignores Estuary's invisible focus-transfer controls.
- Refreshes skin-specific behavior when Kodi changes skins without restarting the service.
- Preserves Tolk output, NVDA 2026.2 support, protected speech queues, navigation replacement, settings accessibility, and the no-SAPI-fallback rule for explicitly selected Tolk.

## Downloads

- `service.xbmc.tts-2.1.1.zip`: install from Kodi's **Install from zip file** command.
- `Kodi-Screen-Reader-2.1.1-Windows-Setup.exe`: installs only the add-on for the current Windows user. Kodi is not included.
- `SHA256SUMS.txt`: verifies both downloads.

The Windows installer is unsigned. Download it only from this repository and verify its checksum.
